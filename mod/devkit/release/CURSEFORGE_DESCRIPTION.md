# ARK Bloodlines Scanner

ARK Bloodlines Scanner adds an **Export to ARK Bloodlines** action to a tamed creature's radial menu. Select it to inspect the creature and display a portable `ABL1:` transfer code, then copy that code into the ARK Bloodlines companion app.

The scanner exports breeding-relevant information including:

- Base/wild and manually leveled stat points
- Species, name, and sex
- Creature ID
- Maternal and paternal mutation counters
- Color regions
- Parent information
- Traits
- Taming effectiveness
- Imprint quality and imprinter

The mod is read-only: it does not alter creatures, breeding, stats, or saves. It does not require OCR, filesystem access, network access, or automatic clipboard access.

**Requires the ARK Bloodlines companion app to import the generated transfer code.**
