# ARK Bloodlines app

This folder contains the complete offline browser app.

Open [`index.html`](index.html) in a modern browser to use it. No installation, build step, web server, or network connection is required. Creature and incubator records are stored in that browser's local storage; use **Data → Export JSON** for portable backups.

The app accepts `ABL1:` transfer codes created by the companion [ARK Bloodlines Scanner mod](../mod/README.md).
