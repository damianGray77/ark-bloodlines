# ARK Bloodlines

ARK Bloodlines is a dependency-free, offline breeding tracker for ARK. It keeps inherited stats, mutations, ancestry, colors, and breeding decisions organized without requiring an account, server, or internet connection.

The repository also includes the companion **ARK Bloodlines Scanner** mod for ARK: Survival Ascended, which transfers creature data from the game into the browser app.

## Features

- **Herd register** — Track inherited points, mutation stacks, player levels, imprint, colors, traits, parents, breeding lines, and category tags. Search, filter, and sort the complete herd.
- **Incubators** — Organize eggs across named ten-slot incubators, retain their full genetic records, and move them into the herd when hatched.
- **Lineage tools** — Explore multi-generation pedigrees, trace individual stats through ancestors, and compare offspring values with both parents.
- **Breeding lab** — Compare breeder pairs, estimate higher-stat inheritance, mutation eligibility, projected base level, and possible color combinations.
- **Genetic quality scoring** — Grade creatures relative to their species and breeding line using configurable goals, mutation capacity, parent progress, and useful traits.
- **Stat calculator** — Estimate displayed stats using bundled species data, imprint, taming effectiveness, player levels, server multipliers, and optional Single Player Settings.
- **Custom creatures** — Define local stat profiles for unsupported or modded species.
- **Portable data** — Import and export JSON backups or copy individual creatures using `ABL1:` transfer codes.

## Getting started

Open [`app/index.html`](app/index.html) in a modern browser. No installation, build step, or local server is required.

Add creatures manually or paste a transfer code generated by the companion [ARK Bloodlines Scanner mod](mod/README.md). Data is stored in the current browser, so export a JSON backup regularly.

## FAQ

### Where is my data stored, and how do backups work?

Data stays in the browser’s local storage. JSON exports include creatures, incubators, calculator settings, custom species profiles, and breeding goals.

Importing a backup replaces the ledger currently stored in that browser.

### How do the scanner and transfer codes work?

The companion ARK Bloodlines Scanner adds an action to a tamed creature’s radial menu and displays a portable transfer code. Copy that code into the creature editor to populate the available fields.

Pasting a transfer code never saves the creature automatically. The scanner does not upload data or write directly to the browser or clipboard.

### Can I use custom server settings or modded creatures?

Yes. Calculator settings support server stat multipliers, imprint scaling, and ARK’s hidden Single Player Settings boosts.

Custom species profiles can be created for unsupported or modded creatures and are stored locally with the rest of the application settings.
